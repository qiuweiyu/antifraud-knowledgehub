# Security Policy

AntiFraud-KnowledgeHub is an early-stage public-interest anti-fraud project.
Security reports are welcome, especially issues involving data leakage,
unsafe sample data, dependency vulnerabilities, authentication mistakes,
or risk-analysis behavior that could expose sensitive information.

## Reporting a Vulnerability

Do not open a public issue with exploit details, secrets, personal data, or
reproducible abuse steps.

If GitHub Private Vulnerability Reporting or repository security advisories are
available for this repository, use that private channel first. If no private
channel is available, open a minimal public issue asking the maintainer to
establish a private contact path, without including sensitive details.

## Data Safety

Do not include real victim data, secrets, credentials, access tokens, bank
cards, ID numbers, phone numbers, private chat identifiers, or unredacted
screenshots in issues, pull requests, logs, screenshots, fixtures, or sample
cases.

All contributed scam cases must be anonymized and should use synthetic names,
placeholder accounts, and non-clickable example links.

## Supported Versions

The project is pre-1.0. Security fixes are handled on the default branch and
released in the next patch release when maintainers can verify the fix.
